What it does

Everything a password manager needs. Nothing it doesn't.

A complete credential workflow in a single native binary — designed to be small enough to read and serious enough to trust.

⛨

Authenticated encryption

AES-256-GCM verifies the 128-bit tag before decrypting. Wrong password and tampering fail closed with the same error.

⌗

Hard key derivation

PBKDF2-HMAC-SHA256 with 210,000 rounds and a random 16-byte salt. The iteration count and salt are authenticated as AAD.

✦

Strong generation

Passwords come from the OS CSPRNG, with configurable length and character classes and at least one character from each selected class.

⌕

Fast retrieval

AND-search across title, username, URL, notes and tags. Look up by full ID or unique prefix; copy without printing.

✂

Clipboard hygiene

A detached helper clears the clipboard after 30 seconds — only if it still contains the same value, verified by digest.

⏱

Crash-safe writes

Temp file plus atomic replace, previous version kept as a backup, owner-only permissions on POSIX. A fresh nonce on every save.

A single flipped bit anywhere in the file invalidates the tag.
  • ✓Header-as-AAD binds magic, version, KDF id, rounds, salt, nonce and length to the tag.
  • ✓Fresh nonce per save avoids the catastrophic nonce reuse that breaks GCM.
  • ✓Real re-keying on password change: new salt, new key, and the stale .bak is deleted.
  • ✓Secrets wiped with an optimizer-resistant secure_zero; clipboard helper sees only a digest.
  • ✓Constant-time comparison for tags and master-password checks.
  • ✓Bounded parser rejects truncation, trailing bytes, oversized fields and duplicate IDs.

Get started

Build it with CMake.

CMake 3.16+ and any C++17 compiler. The same source builds on Windows, Linux and macOS.

Terminal
# clone and build
git clone https://github.com/Beastman12/ciphervault.git
cd ciphervault
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# verify the cryptography
./build/ciphervault selftest

# run the 43 unit tests
ctest --test-dir build --output-on-failure
A typical session
ciphervault init
ciphervault add --title GitHub --generate
ciphervault add --title Bank --username me --generate

ciphervault list
ciphervault search github
ciphervault get github --copy
ciphervault get bank --field username

ciphervault edit github --generate
ciphervault rm old-router --yes
ciphervault audit
ciphervault passwd
ciphervault backup D:\backups\vault.spm
